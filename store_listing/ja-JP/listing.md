# Google Play ストア掲載情報（日本語）

Play Console の「メインのストアの掲載情報」に貼り付ける文面。

## アプリ名（30 文字以内）

```
サッと計算 - 割り勘・消費税・単位変換
```

## 簡単な説明（80 文字以内）

```
割り勘、消費税、年齢・日数、単位変換、割引率。日常のちょっとした計算をこれ1つでサッと。
```

## 詳しい説明（4,000 文字以内）

```
「サッと計算」は、毎日のちょっとした計算をすばやく済ませるための多機能電卓アプリです。
よく使う5つの計算を1つにまとめたので、用途ごとにアプリを探す必要はありません。

■ 割り勘計算
合計金額と人数を入れるだけで、1人あたりの金額がすぐに分かります。
端数の処理方法も選べるので、飲み会や旅行の精算に便利です。

■ 消費税計算
税抜き金額から税込み金額、税込み金額から税抜き金額を計算します。
税率は自由に変更でき、10% や 8% の軽減税率にも対応。消費税額もあわせて表示します。

■ 日付・年齢・日数計算
・日付計算：ある日から◯日後・◯日前の日付を計算
・年齢計算：生年月日から今日の年齢を計算
・日数計算：2つの日付の間が何日あるかを計算
記念日やしめ切りの確認に役立ちます。

■ 単位変換
長さ（mm・cm・m・km・インチ・フィート・マイル）、重さ（mg・g・kg・t・オンス・ポンド）、
温度（摂氏・華氏・ケルビン）、体積（mL・L・m³・ガロン・カップ）を変換できます。
よく使う単位は設定で既定にしておけます。

■ パーセント計算
・割引後価格：元の価格と割引率から、セール後の価格を計算
・増減率：2つの数値から、何% 増えたか・減ったかを計算

■ 計算履歴
計算ごとに直近の履歴を表示。タップすると入力値をそのまま呼び出せます。
履歴は1件ずつ、または計算ごとにまとめて削除できます。

■ そのほかの特長
・シンプルで見やすい画面
・計算結果はタップするだけでコピーできます
・ダークモードに対応
・計算履歴と設定は端末内にだけ保存され、外部には送信されません
・アカウント登録は不要です

※ 本アプリは広告を表示します。
```
